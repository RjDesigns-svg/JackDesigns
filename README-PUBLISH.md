# Rey Jack Crisostomo Portfolio

## Publish with GitHub Pages (free)

1. Create/sign in to a GitHub account.
2. Create a **new public repository** named `reyjackcrisostomo.github.io`
   (replace `reyjackcrisostomo` with your GitHub username).
3. Upload **all files and folders inside this portfolio folder** to the repository.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/ (root)**, then Save.
7. Wait a few minutes. GitHub will show your public portfolio URL.

Your resume can then use:
`https://YOUR-GITHUB-USERNAME.github.io/`

## Alternative: Netlify
You can also drag this whole portfolio folder into Netlify's deploy area. It will give you a public URL immediately, which you can customize later.

## Important
- Keep the folder structure intact when uploading.
- `index.html` must remain at the website root.
- Your artwork is stored under `assets/portfolio/`.
- `index-original.html` is a backup of the original homepage.
